# 📱 «Сладкая Учёба» для Android

Приложение собрано на Capacitor: игра (`index.html`, `app.js`, `words.js`) целиком лежит внутри,
работает без интернета, озвучка — синтезатор речи телефона (Google TTS).

## Как получить APK и поставить на телефон

1. Любое изменение в ветке `main` автоматически собирает приложение (GitHub → вкладка **Actions** → **Android**).
   Можно запустить и вручную: Actions → Android → **Run workflow**.
2. Откройте завершённый запуск (зелёная галочка) → внизу **Artifacts** → скачайте `sladkaya-ucheba-apk`
   (это zip, внутри файл `.apk`).
3. Перекиньте `.apk` на телефон и откройте его. Android попросит разрешить установку из этого источника — разрешите.
4. Новые версии ставятся поверх старых, прогресс ребёнка сохраняется.

**Озвучка иврита.** Если иврит не звучит: Настройки телефона → Синтез речи (Text-to-speech) →
Google → Установить голосовые данные → иврит. Игра сама предупредит, если голоса нет.

## Публикация в Google Play

### 1. Ключ подписи (один раз)

```bash
keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10950
```

Храните `upload.jks` и пароли в надёжном месте — без них нельзя выпустить обновление.
**Не кладите `upload.jks` в репозиторий** (он в `.gitignore`).

### 2. Секреты в GitHub

GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Что положить |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | содержимое `base64 -w0 upload.jks` |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | `upload` |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

После этого сборка выдаёт ещё и `sladkaya-ucheba-aab` — файл для Google Play.

### 3. Google Play Console

- Аккаунт разработчика (разовый взнос $25).
- **Целевая аудитория и контент**: выберите возраст детей (например, 5–8 и 9–12) — так приложение попадает
  в программу «Для всей семьи». Возраст указывается здесь, внутри приложения его спрашивают
  только для подбора сложности.
- **Политика конфиденциальности**: `https://shusandrik23.github.io/kids_training/privacy.html`
- **Безопасность данных (Data safety)**: данные не собираются и не передаются — имя, возраст и прогресс
  хранятся только на устройстве.
- Реклама: нет. Покупки в приложении: нет.
- Загрузите `.aab` в «Внутреннее тестирование», проверьте на телефоне, затем — в рабочую версию.

## Для разработчика

```bash
npm install
npm run sync          # собрать www/ и перенести в android/
npm run apk           # собрать APK локально (нужен Android SDK)
```

- `applicationId`: `io.github.shusandrik23.sladkayaucheba` — после первой публикации в Google Play менять нельзя.
- Номер версии — поле `version` в `package.json`.
- Иконки и заставка — `android/app/src/main/res/`.
