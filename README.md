# 🧁 Сладкая Учёба

Обучающая игра для детей: английский, иврит, русский и математика. Работает в браузере (GitHub Pages),
её можно добавить на главный экран телефона, и она работает без интернета.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и стили |
| `app.js` | логика игры |
| `words.js` | **500 слов** (en / ru / he с огласовками / эмодзи / тема) и все задания. В начале файла — инструкция, как добавлять слова |
| `sw.js` | офлайн-режим. **После любого изменения увеличьте `VERSION`** |
| `manifest.json`, `icons/` | иконка и установка на главный экран |

## Что умеет

- Три языка наравне: «Найди букву», «Найди слог», «Слово из слогов», «Слова (500 слов)» (слово → картинка),
  «Выбери слово по картинке» (картинка → слово), «Слова на слух» (звук → написание),
  «Собери слово по буквам», «Найди пару», «Фразы»; для английского — «Заполни пропуск», для иврита — «Тексты».
- Перед игрой можно выбрать тему (животные, еда, цвета, числа…).
- Слова с ошибками возвращаются чаще, пока не будут выучены (3 правильных ответа подряд с первой попытки).
- Раунд — 10 вопросов, в конце «Ура!». Конфетти и звук за правильный ответ.
- Цель на день и огонёк 🔥 за дни подряд, когда цель выполнена.
- Страница «Для родителей»: сколько слов выучено, где ошибки, сколько занимались по дням.

Числа показываются цифрами, цвета — цветными кружками, фигуры — фигурами. Карточка с русским словом (🔊 сбоку озвучивает его) осталась только у 38 слов, которые невозможно нарисовать. На экране выбора темы можно включить «Только слова с картинками».
